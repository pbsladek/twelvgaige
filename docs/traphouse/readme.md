# Traphouse

The traphouse holds Twelvgaige operator material: drills, workflow shell
examples, and loadout sketches.

- [`drills/`](drills/) contains scenario play-throughs and shell snippets.
- [`workflows/`](workflows/) contains runnable YAML, JSON, and TOML shell
  examples that use local Ollama.

Use these documents as patterns, not as blind runbooks. Each round should keep
control flow in OTP, keep tools bounded by chokes, and put write-capable shots
behind safety.
